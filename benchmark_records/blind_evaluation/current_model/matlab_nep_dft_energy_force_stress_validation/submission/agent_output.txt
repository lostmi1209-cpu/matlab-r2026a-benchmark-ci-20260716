Implemented a standalone MATLAB solution that parses EXTXYZ and HDF5 inputs, validates structure_id and atom_id set equality, aligns all predictions by identifiers, computes required overall and material-group metrics, writes per-structure residuals, evaluates training convergence/generalization, solves the exact bounded regularized calibration with lsqlin, and fits required Normal residual distributions with fitdist. The code normalizes transposed HDF5 component matrices and reports explicit strict-convexity diagnostics, solver status, objective value, and calibrated parameters. MATLAB was unavailable locally, so validation was limited to static inspection.
