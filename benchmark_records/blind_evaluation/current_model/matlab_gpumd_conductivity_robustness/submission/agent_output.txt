Implemented a MATLAB entry point that reads all 81 public trajectories, validates their time axes and post-burn-in sample counts, reduces each trajectory to one independent run estimate, and computes the required material summaries, 95% intervals, robustness measures, ordering, and constrained size-convergence fits. The implementation calls normcdf and lsqcurvefit at runtime, writes all three requested result files, rejects nonfinite outputs, and does not embed any expected numerical result.
